Bienvenido al Portal Cliente

Esta página web forma parte del proyecto académico Protecta Solutions, desarrollado por estudiantes de la carrera de Programación del plantel CECYTEH.

¿Por qué se elaboró esta página?

Se elaboró para demostrar de forma práctica el uso de HTML, CSS y JavaScript en un sistema real: un catálogo de productos de seguridad electrónica (alarmas, acceso, videovigilancia, fibra óptica, etc.), con vista para clientes y panel de administración para la empresa. El objetivo es aplicar lo aprendido en clase a un caso cercano a la industria.

Audiencia

Está dirigida a clientes y personal de Protecta Solutions, y a docentes evaluadores del plantel CECYTEH.

Usa el menú para ver productos, autoría, referencias, descargas y contacto. Síguenos en redes con los botones de arriba.

Objetividad y propósito

Motivos de elaboración

  • Aplicar HTML, CSS y JavaScript en un proyecto integral.
  • Simular un portal real de empresa de seguridad electrónica (Protecta).
  • Separar roles: vista de cliente (solo consulta) y vista de empresa (edición).
  • Cumplir criterios de evaluación de página web académica.

Este sitio no tiene fines comerciales ni publicidad pagada; es un trabajo escolar de demostración.
